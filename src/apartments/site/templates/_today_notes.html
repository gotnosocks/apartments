Where these prices come from

The model is {{ info.model }}, fitted as {{ info.run }} on every ad up to {{ day(horizon.last_ad_day) }} {% if info.gate and info.gate.passes %}(it passed the convergence gate: {{ info.gate.chains }} chains, worst split R-hat {{ "%.4f"|format(info.gate.max_rhat) }}){% endif %}. Prices use {{ info.draws.kept }} of its saved posterior draws, and are for {{ "{:,}".format(info.apartments.all) }} apartments.

{% if horizon.days_past > 0 %}

The market trend stops before today. The model's citywide trend runs to {{ day(horizon.grid_end) }}, {{ horizon.days_past }} day{{ "" if horizon.days_past == 1 else "s" }} before {{ day(info.day) }}. For those days the trend is carried on as the model describes it, a random walk that has drifted {{ pct(horizon.drift_pct_month) }} a month on average, which adds {{ pct(horizon.added_pct, signed=False, digits=1) }} of uncertainty to every price. Each building's and apartment's own movements are carried forward the same way.

{% else %}

The model's citywide trend reaches {{ day(info.day) }}, so no extrapolation is needed.

An apartment the model has no earlier ad for is priced as a new apartment in its building, with a wider range. The price assumes the apartment is as its newest ad described it. Model outputs, not appraisals: they describe asking rents.
