# JUDGE: BEN'S GOAL: scientific value as Ben's standing instructions define it. That mean

BEN'S GOAL: scientific value as Ben's standing instructions define it. That means explanatory terms over descriptive ones (move variance out of building, walk, slope, unit and label terms into named features), parsimony and interpretability, honest uncertainty about each factor and about the final asking rent, and generalization rather than fit to particular observations. My reading of the pack under this priority: only one candidate, LLM grades of finish quality from photos, has a plausible path to moving building variance into a named feature. Every other candidate meant to add explanation either has evidence against it (amenity codes, coded concessions, GraphQL size digests) or is a label term by construction (the West Village step). So the plan pairs that one lever with four measurements, each with its own job: (a) building-clustered scoring, which makes per-factor and new-building uncertainty honest and gives every later verdict an SE; (b) the as-of explanation ceiling, which says whether data already held can move building variance at all; (c) an unseen-area refit, which tests whether the explanations generalize; (d) the time-split refit, which makes the published new-unit range honest. Model-term fits (the AR(1) walk, the bedroom-curve swap, the WV step) rank below these. The stopping rule (prior review :351) points away from more model terms, and none of these fits is predicted to move the new-building miss or the descriptive share.
