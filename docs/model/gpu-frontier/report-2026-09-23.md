## Inference

A structured blocked Gibbs sampler written in JAX, running in float64 on a GPU. Each
iteration draws every latent effect jointly and exactly: coefficients, market-curve knots,
season, each building's block (level, bedroom slope, 34 walk knots) and each unit.
Unit effects are integrated out analytically, and building blocks are eliminated with
batched Cholesky factors. Group scales and σ get a collapsed Metropolis update, with all
latents integrated out, computed from the same factorisation. The slowest scales also
get one-dimensional collapsed updates. Correctness tests:

- the joint draw matches a dense solve to 1e-8 (five designs);
- the collapsed marginal likelihood matches a dense multivariate normal;
- a Gibbs state maps exactly to the NumPyro model's linear predictor;
- posterior moments match NumPyro NUTS on synthetic data (MCSE-based test; base, walk
  and full designs).

## Update (2026-09-24): m7, Student-t unit effects. New current best

**A gate correction first.** The convergence gate used to check R-hat on 32 randomly
traced buildings. It missed a bimodal building (110 W 26th: 1,600 sq ft lofts next to small
unsized 1-bedrooms) in every m6 run, where 3 of 16 chains sat in another mode. The gate now
also requires max R-hat < 1.05 over every element of every effect: all buildings, walk
knots, slopes and units. It is computed from exact per-chain moments; for older runs it
is recomputed from kept draws, at a 1.1 threshold. **All m6 runs fail it.**

**m7 = m6 + Student-t unit effects** (u_j ~ t(ν_u, 0, τ_u), ν_u estimated). A few
genuinely different units can then sit far from their building instead of bending its
slopes. That removes the 110 W 26th bimodality and is the largest single gain so far. It
needed sampler work:

- the Student-t unit prior as a Gamma scale mixture, so it stays exact inside the block
  elimination;
- a collapsed per-unit κ update with the unit effect integrated out;
- a per-unit mode hop ("unusual unit" vs "unusual listings"), with row weights and κ
  integrated out;
- a joint (τ_u, ν_u) update.

Each of these passes the dense-solve and NUTS-agreement tests.
