## Current best: `m8-drift/desc-v1`, commit `b7c196f` (tag `frontier-m8-b7c196f`)

m8 = m7 (m6 + Student-t unit effects) plus a **per-unit linear drift** in log rent per year,
centred on the unit's mean training date. In the sampler each unit becomes a 2×2 block
(level, drift), still eliminated exactly inside each building. Unseen units in the unit
split integrate the level over its Student-t prior with the scale widened by the drift
variance, √(τ² + τ_d² t²). That is exact for Gaussian units and an approximation for
Student-t units.

All four runs pass every gate: max scalar R-hat ≤ 1.006, max R-hat over every building,
walk, slope, unit and drift effect ≤ 1.018, and min ESS ≥ 2,573.
