## Raw layer

The scraper thread runs the collector, and it agreed on 2026-10-15 to export every stored API answer
as append-only Parquet. Its module `streeteasy_archive/graphql_export.py` reads the archive
read-only, and `ops/streeteasy-collect` runs it after each region's invocation. The layout:

- `/data1/apartments/archive/crawls/api/export/manifest.ndjson`, one line per file written.
- Records: at most 250 responses per file. Each row carries `listing_id`, `fetched`,
  `response_id`, `run`, `region`, `generation`, `outcome`, `record_sha256` and `record`, where
  `record` is `json.dumps(record, sort_keys=True)` with default separators and `ensure_ascii`, so
  its SHA-256 equals the archive's own record hash.
- Requested ids come from the stored request URL, and requests include `url_length`. Only
  answered requests appear.
- Calls go to `export/calls/run-000N/rows-FIRST-LAST.parquet`, keyed by `rowid`.
- Run 5 reads no unit histories.

The exporter merged in #863, and it wrote runs 1 to 4 by 17:03 ET on Oct 15. Run 5 follows once
the collector finishes it. #863 also writes a `requests` table, one row per stored reply with its
Oxylabs job ID, status codes and body paths. From the export, the trial's SQL gives the same
latest ask as `rentfrontier.latest_ask` on every row of the four regions.
