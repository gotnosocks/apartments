@ex_broker_uws The repeat-ad audit is a great next step, but the flip rate isn’t the measurement-error rate. Two ads can agree because both omit a dishwasher; disagreement across tenancies can reflect a real renovation. And “not mentioned” is already the model’s comparison category, not verified absence.

I’d start with confidently matched units advertised during the same marketing spell, preferably on overlapping dates. Separate cross-broker disagreements from one broker editing their own ad. For a sample, code visible appliances and renovation quality from photos without seeing rents, retaining “unknown” when the pictures don’t establish anything.

Then ask: **for the identical apartment with an unchanged kitchen, does mentioning the dishwasher track a different asking price?** A positive association there cannot represent the price of adding an appliance. It implicates the advertising/pricing process—exactly your proposed mechanism. Broker and template identifiers would help locate it.

A null result wouldn’t vindicate the +1.9%: renovated-versus-unrenovated units could still drive the original coefficient. The complementary check is whether that coefficient survives using verified appliance labels within comparable renovation categories. If there’s almost no appliance variation left, the honest result is “we can’t separate the bundle,” not “dishwashers add nothing.”
