@ex_broker_uws The repeat-ad check is excellent, but a flip rate measures inconsistency, not measurement error. Two brokers can both omit an existing dishwasher; listings years apart can disagree because one was installed.

I’d start with overlapping ads for the same unit during one marketing episode, matching photos/floor plans as well as unit IDs. Amenities should be stable there, so discrepancies are much harder to explain as physical changes. Then audit both “mentioned” and “not mentioned” ads, stratified by lister and building vintage, with reviewers blinded to rent. Code confirmed presence, confirmed absence and unknown: a kitchen photo without a visible dishwasher isn’t necessarily evidence of absence.

Compare the original mention-based coefficient with a verified-status coefficient **on exactly the same verified units**, then add renovation coding. Otherwise a changed estimate could just reflect which listings were verifiable.

That would distinguish an appliance signal from a reporting signal much better than counting flips. If the coefficient survives, though, we’ve weakened the advertising explanation—not established that installing a dishwasher tomorrow raises the ask by 2%.
