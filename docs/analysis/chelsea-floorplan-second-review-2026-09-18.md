# Four more floor plans: bedroom access versus office access

Four additional floor plans were collected through Oxylabs using exact URLs
already recorded in the archive. All four depict two full bathrooms, no half
bath, and one bedroom-suite bathroom. Two independently inspecting agents agree
on the count and room/door topology. The first and second batches together cover
all eight initially selected source references.

| Advertisement | Depicted access | Source qualification |
| --- | --- | --- |
| 3080726 | Primary-suite bath plus foyer bath | Flow Chelsea, Unit A, Floor 24 and address visible; artist-rendering disclaimer |
| 4799624 | Primary-suite bath plus common bath | No visible address or unit label; second bedroom and bath separately enter common circulation |
| 4320516 | Primary-suite bath plus hall/office bath | No visible address or unit label; office access is not bedroom access |
| 5064467 | Primary-suite bath plus common bath | Visible 252 West 30th Street, Apartment 2B label matches the source reference |

In ad4320516, the primary bathroom opens to dressing circulation within the
bedroom suite. Its hall door is the suite entrance; there is no separate door
between the labeled bedroom and its closet vestibule. The other bathroom has two
doors, one to the hall and one to an area explicitly labeled **OFFICE**. The
separate second bedroom has no bathroom connection. Generic two-door counts would
misrepresent this distinction.

This batch still provides no clean one-versus-two en-suite comparison at the same
bedroom/full/half configuration. It supports measurement development, not an
en-suite coefficient. Absence of such a comparison in this selected pilot does
not establish absence in the wider archive. The next useful sample should target
complete all-en-suite inventories and composition-matched alternatives.
