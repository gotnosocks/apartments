# Chelsea asking-rent analysis — September 8, 2026

The scraper, live raw archive, archive browser, import pipeline, and pricing analysis
now live in `apartments`. The preceding state is preserved on
`archive/pre-chelsea-model-20260908`; this version is on `feature/chelsea-analysis`.

## Data used

The imported rental archive contains **317 units across 163 buildings** and **8,441
history events**. This is the usable rental history in the current crawl, not every
Chelsea unit or lease. The raw archive also contains building and sale pages.

The model uses **2,386 monthly observations from
287 units across 147 buildings**, from April 2006
through September 7, 2026. It excludes 30 units with explicit furnished/Blueground
evidence, including their earlier history. Three events are invalid or lack a
usable price/date. Repeated capture/event rows are deduplicated before taking
one median price per unit and calendar month.

Unknown/unsupported floor information occurs in 767 modeled observations; square
footage is missing in 1,104. These observations remain in the model with explicit
missingness handling. Unit attributes use the newest listing episode rather than
an older episode that happened to be scraped later.

## Model and results

The model combines a shared monthly random walk with pooled building and unit
effects, categorical floors, bedroom/bathroom/size controls, and Student-t log-rent
residuals. It no longer hard-codes five buildings or Sierra-specific coefficient
interpretations. Building effects are centered on the modeled-building mean.

| Comparison | Median adjusted asking-rent change | 95% credible interval |
|---|---:|---:|
| January 2022 to September 2026 | +22.2% | +17.5% to +27.2% |
| September 2025 to September 2026 | +6.9% | +4.3% to +9.7% |

These intervals come from posterior differences, accounting for correlation between
months. September 2026 includes only the first seven days. Monthly support varies
substantially: September 2025 has 21 units with events, January 2026 has 2, August
2026 has 198, and September 2026 has 138. The dashboard shows this coverage beside
the index. Selection effects are not included in the credible intervals.

Conditional on the other model controls, an additional bedroom is associated with
11.9% higher asking rent (95% interval 6.1–18.1%), and an additional bathroom with
17.4% (11.3–24.4%). These are model associations, not causal premiums.

## Validation

A separate four-chain fit withheld all prices from January 2026 onward:

| Metric | Result |
|---|---:|
| Withheld observations | 459 |
| Previously seen-unit observations | 377 |
| Median absolute percentage error, all withheld observations | 6.51% |
| Same error, previously seen units | 6.08% |
| Last-observed-rent baseline, same previously seen units | 11.61% |

This is a **retrospective price test**: latest captured attributes and full-data
size scaling are retained. It is not a fully time-causal backtest. Newly appearing
units use pooled/prior effects. Repeated unit observations are not independent.

The full fit used 1,000 tuning and 1,000 posterior draws per chain, with four chains.
Its maximum R-hat is 1.0057, minimum bulk effective sample size is
819, and it has zero divergences. The refined validation fit used
1,500 tuning and 2,000 posterior draws per chain: maximum R-hat 1.0067,
minimum bulk ESS 753, and zero divergences. Unrounded diagnostics
are saved to avoid hiding convergence warnings.

## Use and reproduce

- Analysis app: http://localhost:8501/Bayesian_Model
- Live archive browser: http://localhost:8765/
- Model inputs, posteriors, validation predictions, diagnostics, and manifest: `data/model/monthly/`
- Durable raw source: `data/archive/`

```sh
cd ~/code/apartments

uv run --locked apartments import-archive

  --validation-draws 2000 --validation-tune 1500
uv run --locked --extra app streamlit run app.py --server.port 8501
```

source tree; the old standalone repository is not required to run this version.
Raw data was relocated without new StreetEasy downloads. Incremental import skips
all 2,729 catalogued listing snapshots after classification; failed imports roll
back only their own writes and remain retryable.

Verification: 79 tests passed, one optional browser test skipped. Both local apps
responded successfully, and the explorer and model dashboard passed runtime tests.

## Limits and next useful work

A drained discovered URL queue is not proof of a complete building/unit inventory.
The strongest next data improvement is broader unavailable-unit discovery and
coverage auditing, rather than more precision from the same observed subset.
Historical changes of layout or furnishing are not reconstructed; latest attributes
can misdescribe older episodes. Asking rents, removed prices, and rented-status
prices are not evidence of signed lease amounts. Treat the index as a description
of this archived sample, not a population-weighted Chelsea rent benchmark.
